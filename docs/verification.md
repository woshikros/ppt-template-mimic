# 验证范围

验证日期：2026-11-06。

独立项目包含五项可重复测试：

- 模板页面顺序、组合内对象、重名对象和原生表格分析。
- 新稿生成、文字替换、可编辑组合和表格内容、原件不变。
- 页数不符或对象选择有歧义时停止，不写出错误结果。
- 拒绝覆盖原件及已有输出。
- 检查预期页数不符。

执行 `node --test tests/workflow.test.cjs`，五项均通过。测试模板来自 `tools/create-fixture.cjs`，全部内容为虚构，不包含公司模板。

提取为独立项目之前，相同核心代码还在两种真实模板上各生成三页：蓝色组合图模板和橙白原生表格模板。六页完成了结构检查、PowerPoint 打开和逐页查看，并核对了文字、语言标记、原图像资源和表格等。真实参考及测试稿不进入仓库。

这些检查不等于支持所有 PPT 特性；复杂动画、媒体、特殊图表及合并表格不在通用适配保证范围内。
