# 分享封面

封面文件：`assets/social-preview.png`；可编辑设计源：`assets/social-preview.html`。

PNG 尺寸为 1280×640，小于 1 MB，符合 GitHub 推荐的社交预览规格。HTML 为自包含设计，不读取网络字体、公司材料或外部图片。

README 顶部已经展示封面。README 图片与 GitHub 的 Social preview 是两项不同的设置；仅提交图片不会自动替换链接卡片。

GitHub 只允许从公开仓库向外分享这类预览。公开仓库后，在 Settings → General → Social preview → Edit → Upload an image 中选取 PNG。公开可见性属于单独的发布操作，不能仅因准备了图片就自动开启。

平台可能缓存旧链接预览，因此设置成功后不保证 X 立刻更新。可以直接把 PNG 作为帖子配图使用；直接配图无需等待链接卡片更新。

官方依据：[Customizing your repository's social media preview](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)。
